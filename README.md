# Travel-Locator# 🌍 Travel Locator (Family Travel Tracker)

A simple web application that allows users to track countries they have visited. Each user can have a custom profile (name and color), and the app keeps track of the countries each user has marked as visited.

## 🚀 Features

- Add countries to a user's visited list
- Switch between multiple users
- Create new user profiles
- Display total visited countries on the world map (via `index.ejs`)
- PostgreSQL database integration

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Templating Engine:** EJS
- **Middleware:** body-parser
- **Frontend:** HTML/CSS (inside `public/` folder)
